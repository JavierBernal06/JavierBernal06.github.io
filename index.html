Blogs (Proyectos sin repositorio)

Sistema CRUD de Administración de Materiales de una Minería

  • a. Descripción: Un sistema de base de datos diseñado para gestionar y administrar eficientemente el inventario de materiales utilizados en operaciones mineras, integrando un módulo de autenticación de usuarios.
  • b. Requerimientos del cliente: El cliente necesitaba una plataforma segura que permitiera el control estricto de entradas y salidas de recursos, registro de usuarios autorizados, y una interfaz que facilitara la actualización constante del stock de materiales pesados.
  • c. ¿Cómo se diseñó la solución?: Se propuso una arquitectura cliente-servidor. El diseño se centró en una base de datos relacional robusta que garantizara la integridad referencial entre los usuarios, los almacenes y el catálogo de materiales.
  • d. ¿Cómo se implementó la solución?: Se desarrolló el backend configurando rutas para el manejo de sesiones de usuario y operaciones CRUD (Crear, Leer, Actualizar, Eliminar) directas sobre la base de datos relacional para gestionar el inventario en tiempo real.
  • e. ¿Cuál fue el resultado?: Se entregó una plataforma funcional que digitaliza el control de inventarios de la mina. Esto permite a los administradores tener trazabilidad de los materiales, reduciendo errores humanos en el conteo y asegurando que los recursos estén disponibles cuando se requieren en la operación.
